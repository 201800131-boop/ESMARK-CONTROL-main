# ESMARK-CONTROL

## Servidor local compartido

Para mover los datos de Supabase Cloud a un servidor de la oficina y compartirlos entre todas las computadoras, sigue [docs/SERVIDOR_LOCAL_ESMARK.md](docs/SERVIDOR_LOCAL_ESMARK.md). Los scripts numerados preparan el servidor, migran los datos sin borrar la nube, construyen el instalador local y programan respaldos diarios.
